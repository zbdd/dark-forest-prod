# Raw Assets Guide

Place raw art, audio, and sprite assets here. AssetPack processes them into `public/`.

## Directory Structure

```
raw-assets/
├── tiles/          ← Ground and terrain tiles
├── buildings/      ← Building sprites
├── entities/       ← Worker and creature sprites
├── ui/             ← UI icons and elements
├── sfx/            ← Sound effects
└── music/          ← Background music loops
```
